# 📊 Enterprise Sentiment Analysis Dashboard

A modern, responsive, and enterprise-grade web application built with **Python**, **Flask**, **TextBlob**, and **Bootstrap 5** that performs real-time Natural Language Processing (NLP) sentiment analysis, complete with dynamic data visualizations and historical tracking.

---

## 🚀 Features

* **Real-Time NLP Analysis:** Instantly evaluates user input text or customer reviews to compute Polarity and Subjectivity scores.
* **Dynamic Visualizations:** Generates an automated, real-time Matplotlib pie chart tracking the distribution of Positive, Negative, and Neutral sentiments.
* **Analysis History Logging:** Maintains a responsive table logging recent searches for quick auditing and reference.
* **Modern Enterprise UI:** Designed using Bootstrap 5 for a sleek, responsive, and professional dashboard layout.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **NLP & Data Processing:** TextBlob
* **Data Visualization:** Matplotlib, NumPy/IO
* **Frontend:** HTML5, Bootstrap 5 CSS Framework
